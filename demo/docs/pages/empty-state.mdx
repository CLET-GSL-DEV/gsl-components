# EmptyState

Illustrated empty state for when a table or list has nothing to show. The parent keeps rendering its headers — this fills the body with the artwork, a configurable title and description, and an optional action slot. Pass the action button you want (or nothing); it is never hardcoded.

## Icon medallion

Pass `icon` for a small muted glyph in a circle instead of the default artwork: a text glyph (`"+"`, `"?"`, `"!"`) or an icon node. An explicit `illustration` (including `null`) always wins over `icon`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `illustration` | `ReactNode` | — | Artwork above the text at the Figma proportions (363×271). Omit for text-only. |
| `icon` | `ReactNode` | — | Glyph in a muted medallion instead of the artwork. Ignored when `illustration` is set. |
| `title` | `ReactNode` | — | Heading, e.g. "No certificates yet". |
| `description` | `ReactNode` | — | Supporting copy under the heading. |
| `action` | `ReactNode` | — | Optional action slot, e.g. a `Button`. |
| `classNames` | `EmptyStateClassNames` | — | `root`, `illustration`, `icon`, `title`, `description`, `action` overrides. |
| `className` | `string` | — | Merged onto the root. |

## Types

### EmptyStateProps

Title plus optional illustration, description, and action. Forwards `ref` and spreads `...props` (e.g. `aria-*`, `id`, `data-*`) onto the root.

### EmptyStateClassNames

| Key | Applied to |
|-----|------------|
| `root` | Outer column |
| `illustration` | Artwork wrapper |
| `icon` | Icon medallion (`.clet-empty-state__medallion`) |
| `title` | Heading |
| `description` | Supporting copy |
| `action` | Action slot wrapper |

## Notes

- Pair with `Table`'s `emptyContent` prop to render this under the table headers when data is empty:
  ```tsx
  <Table
    columns={columns}
    data={[]}
    emptyContent={
      <EmptyState
        title="No certificates yet"
        description="Add certificates, policies and staff records."
      />
    }
  />
  ```
- The illustration is decorative (`aria-hidden`); keep the meaning in `title`.
